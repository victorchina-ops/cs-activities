# פעילויות במדעי המחשב - כיתה י' (מעלה שחרות)

אתר: https://victorchina-ops.github.io/cs-activities/

- `code-workshops/` - סדנאות כתיבת קוד ב-C# (פרקים 2-3): שלוש סדנאות, תשע משימות, תהליך של שישה שלבים, מריץ C# מובנה בדפדפן, ושמירת התקדמות ב-Google Sheets דרך Apps Script (`code-workshops/backend/`).

בדיקות (מקומי): `node code-workshops/tests/csrun.test.js`, `node code-workshops/tests/diff/run_diff.js`, `node code-workshops/tests/ui_smoke.js`, `node code-workshops/tests/ui_all_tasks.js`.
