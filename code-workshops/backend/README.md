# backend - הגשות התלמידים לגיליון (Google Apps Script)

הקובץ `Code.gs` הוא השרת של הסדנאות. הוא נקשר לגיליון Google, שומר בו את כל הפעילות של התלמידים, ומחזיר להם את ההתקדמות שלהם.

## הקמה (פעם אחת)

1. פתחו גיליון Google חדש (או השתמשו בגיליון קיים שייעודי לסדנאות).
2. מתוך הגיליון: **תוספים > Apps Script**. מחקו את הקוד שמופיע שם, הדביקו את כל התוכן של `Code.gs` ולחצו על שמירה.
3. בחרו בתפריט הפונקציות את **setup** ולחצו **הפעלה (Run)**. בפעם הראשונה Google יבקש הרשאות - אשרו אותן עם חשבון המורה.
4. חזרו לגיליון. צריכים להופיע הטאבים: **אירועים**, **סיכום**, **תלמידים**, **הגדרות**. אפשר למחוק את הטאב הריק שהיה בגיליון מההתחלה.
5. **פריסה (Deploy) > פריסה חדשה (New deployment)**. בסוג בחרו **אפליקציית אינטרנט (Web app)**. ב"הפעלה בשם" בחרו **אני (Me)**, וב"מי יכול לגשת" בחרו **כל אחד (Anyone)**. לחצו **פריסה** והעתיקו את הכתובת (URL) שמסתיימת ב-`/exec`.
6. הדביקו את הכתובת בשדה `ENDPOINT` בקובץ `js/config.js` של האתר, ובדקו שהערך של `APP_KEY` שם זהה לערך של APP_KEY בטאב **הגדרות**.
7. לבדיקה: בחרו בתפריט הפונקציות את **testInsertSample** והפעילו אותה. בטאבים **אירועים**, **סיכום** ו**תלמידים** יופיעו שורות של תלמיד בשם "בדיקה" (טלפון 0500000000). אחרי הבדיקה אפשר למחוק את השורות האלה.

## סגירת ההגשות

- בטאב **הגדרות** שנו את הערך של `ACCEPTING` ל-`לא`. התלמידים יקבלו הודעה שההגשות סגורות.
- להחזרה לפעילות שנו שוב ל-`כן`.

## עדכון הקוד בלי לשנות את הכתובת

כך מעדכנים את השרת אחרי שינוי ב-`Code.gs` בלי שהכתובת (URL) תשתנה:

1. ב-Apps Script לחצו **פריסה (Deploy) > ניהול פריסות (Manage deployments)**.
2. לחצו על סמל העריכה (עיפרון) של הפריסה הקיימת.
3. בשדה **גרסה (Version)** בחרו **גרסה חדשה (New version)** ולחצו **פריסה (Deploy)**.

אל תיצרו "פריסה חדשה" - זה יוצר כתובת חדשה, והאתר לא יתחבר אליה.

## הערות למורה

- הציונים שלכם: העמודות **ציון מאושר** ו**הערות מורה** בטאב **סיכום** נכתבות ידיכם בלבד. הסקריפט לא נוגע בהן.
- הטאב **אירועים** הוא יומן שרק מוסיף שורות. אין בו מחיקה ואין עדכון.
- העמודה האחרונה (T) בטאב **סיכום** מוסתרת (שניות, לחישוב זמן כולל). אל תמחקו אותה.
- אם משנים את הקוד של `setup` או מוסיפים טאבים, מריצים שוב את **setup** - זה בטוח ולא מוחק נתונים קיימים.
